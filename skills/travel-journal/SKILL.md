# 维护皖南秋日摄影自驾路书

本仓库是这份路书的源文件，发布为 `https://real-jacket.github.io/trip-anhui/`。保留暖纸色、深绿的摄影杂志风；访客页面只呈现旅行所需信息，研究和技术说明放在 `docs/` 或 `work/`。

## 定位与范围

先读仓库的 `AGENTS.md`、`README.md` 与 [维护指南](../../docs/maintain.md)。本技能的维护副本位于仓库 `skills/travel-journal/`，解析 `SKILL.md` 的真实文件路径后，上两级是仓库根；本地技能入口可能是指向此目录的符号链接。

检查当前 Git 状态和实际源文件，保留无关改动。路书是四天候选计划（`planned`），不是已订或已完成的行程；改动只依据本次需求和可核对的来源，不凭空补日期、酒店、价格或机位。

## 执行分工

协调者（主模型）负责需求与路线分析、计划、设计决策和独立最终验收；执行委派给用户指定的 Sonnet 5.5 子代理，推理强度 high，分派时写明目标文件、预期行为与验收证据。执行者自报不能替代协调者验收，发布遵守当前授权。细则见 [维护指南的执行分工](../../docs/maintain.md#执行分工)。

## 执行

1. 明确本次要改什么：日期窗口、方案或行程、机位与成片、住宿餐饮补能、地图，或仅文档。缺少会改变路线的事实时只询问必要信息，其他可独立工作继续推进。
2. 更新机位或现场信息前先核本地依赖与原作出处。小红书、抖音、B站调研使用 agent-reach 技能（先跑 `agent-reach doctor --json`），按 [调研手册](references/research.md) 执行；原始资料放 `work/research/`，并与文旅、景区、气象、运营方和吃住资料交叉核对。无法完整读取时保留具体边界，不伪造已观看或精确机位。
3. 修改 `site/index.html`，保留运行必需的相对资产、照片署名与全部交互，以及桌面、手机都可见、指向 `https://real-jacket.github.io/travel-journal/` 的“回旅行首页”链接。不要复制私有地图配置、平台临时签名或整个研究目录。
4. 日期、状态、路线或封面变化时同步 `site/trip.json`（首页读取它；署名必填，本人照片的 `imageSource` 可为空）。
5. 地图：编辑 `map.json`，用 `pnpm map:build --routes|--extract [--dry-run]|--landcover|--validate` 生成 `site/map/`，合计不超过 40 MB；定稿后不要反复重建。
6. 执行 `pnpm check`；自己运行 `pnpm preview`，用真实浏览器核对 1280px 桌面与 390px 手机：地图渲染、控制台无错误、无横向溢出、返回首页链接、本次改动涉及的交互。测试通过不能替代运行和视觉证据。
7. 仅当本次用户已要求上传或上线：按授权提交并推送，等待该 commit 的 Pages 工作流成功，打开公网站点与 `trip.json` 验证。仅要求草稿或本地修改时，交付该范围的实际结果。

## 内容标准

- 拍摄参考选择能学习构图的本人作品，明确地点、地面/平台/岸边/航拍视角和可进入方式。原作拍摄日、发布日期、原 EXIF 与本路书参数建议分开；成片后期、叶色与雾的未知情况标清。署名和原帖不是自动转载授权。
- 地图用共用 `TripMap` 模块和 `pnpm map:build` 生成的数据：土地覆盖着色（森林/植被/农田/城镇/水体）加山体阴影、分级路网（高速/国省道/县道/乡道，含编号）与行政境界地名、按天的真实道路路线和中文图例；国界与争议线不画。地图下方保留按段的“用高德查看路线”清单（起点 → 途经 → 终点，GCJ-02，驾车模式）；详细机位信息放在侧栏。真实道路轨迹与方向示意分别标清，停车入口与景区参考中心不能混用。
- 日程给交通、吃饭、睡眠和停拍留时间；电车行程使用实测续航与电池信息安排补能。住宿逐晚匹配下一处机位；历史设施/消费与当前可用性/预算分开。
- 候选计划用 `planned`；若改成历史记录用 `archived`，不因日期已过声称旅行实际完成。

## 交付

说明更新了什么、可用入口、检查证据，以及当天现场信息、网络依赖或图像许可的具体未核实项。不新增后台、账号或数据库，也不授予未来任意发布权限。
